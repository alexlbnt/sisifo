# Registro de peso — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Registrar pesagens (kg), mostrar a tendência num gráfico e medir o peso contra uma meta com faixa de ritmo.

**Architecture:** Coleção nova `bodyWeights` na store pessoal, sincronizada e no backup como as outras listas. Cálculos (média de 7 dias, ritmo por regressão, platô, estado do ritmo) em funções puras em `src/features/personal/weight/`. A meta ganha a fonte `bodyweight`; captura, Treino, Hoje, Metas e revisão leem desses módulos.

**Tech Stack:** React 19, TypeScript, Zustand (`persist`), Zod 4, Recharts, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-25-peso-design.md`

## Global Constraints

- Nenhum arquivo novo em `api/` (11 de 12 no plano Hobby). A captura usa `api/capture.ts`.
- Sem migration de banco: o servidor guarda registros genéricos.
- Uma pesagem por dia: `id` = `date` (`YYYY-MM-DD`). Registrar de novo no mesmo dia substitui.
- `kg` de 20 a 300, até 1 casa decimal (arredondar com `Math.round(kg * 10) / 10` ao gravar). Nota até 200 caracteres.
- Datas como `YYYY-MM-DD`, comparadas como texto. Funções de data de `@/lib/dates` (`addDaysISO`, `daysBetween`, `todayISO`) no app; `src/shared/` usa só imports relativos com `.js`.
- Faixa de ritmo padrão: ganho (alvo > início) **0,25 a 0,5 kg/semana**; perda **0,25 a 0,75 kg/semana**.
- Textos em português do Brasil, números com vírgula (`toLocaleString('pt-BR')`), campos de 16px no celular.
- Store pessoal: `version` de 3 para **4**.
- Site sobe para **v1.13.0** (`package.json`). O desktop não muda.
- Testes rodam pelo PowerShell (`npx vitest run <arquivo>`), não pelo Git Bash.

## Review Focus

- **Pesagem só de dias antigos** (a última há mais de 7 dias): a tendência é levada adiante, o card mostra a data da última pesagem ("última em 02/11") e não some. Teste em Task 2 (`trendAt` com lacuna).
- **Duas pesagens no mesmo dia em aparelhos diferentes:** o id é a data, então vira um registro só; a lista nunca mostra duas no mesmo dia. Teste em Task 1 (`setBodyWeight` substitui).
- **"peso" dentro de uma tarefa ou despesa** ("comprar peso de papel 12", "ver peso 70 amanhã às 9h"): só vira pesagem quando a frase **começa** com `peso` e o resto é só o número (com `kg` opcional). Teste em Task 4.
- **Número com ponto ou vírgula e unidade colada** (`peso 68.4kg`, `peso 68,4 kg`, `Peso: 68`): todos valem. Teste em Task 4.
- **Meta de peso sem prazo e com alvo menor que o início:** a direção vem de alvo × início e a faixa padrão é a de perda. Teste em Task 3 (`paceStatus` em perda).

  ```ts
  export function trendSeries(weights: BodyWeight[]): Array<{ date: ISODate; kg: number; avg: number }>;
  /** Média de 7 dias da última pesagem até `date`, levada adiante; null sem pesagem até a data. */
  export function trendAt(weights: BodyWeight[], date: ISODate): number | null;

  /** trendAt(hoje) − trendAt(hoje − 14); null se algum lado for null. */
  export function change14(weights: BodyWeight[], today: ISODate): number | null;
  ```
